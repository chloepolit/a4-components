## To Do Manager

Host Link: https://a4-chloepolit.onrender.com 

The to do manager is an application that helps the user keep track of tasks and deadlines.
This iteration I added the React componentization of each row of the task table and the whole list itself, also adding different color indicators for categories and priority levels to help highlight more urgent work-related tasks to the user. The new technology improved the development experience by using the component of each level of the table to simplify updating and deleting data through both the return statements and the button functionalities. Using react also made it easier to understand the different levels of category and priority utilizing the component styling. The table updates as it did before, leaving the login and add task form as they were in A3.
